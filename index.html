Pregunta 1

  1. ¿Qué es HTML y para qué se utiliza en el desarrollo web?

Es un lenguaje de marcado para crear páginas web. Se utiliza para crear y organizar el contenido de las páginas web, como textos, enlaces e imágenes, y sirve como base para aplicar estilos y funciones con CSS y JavaScript.

Pregunta 2

  1. ¿Qué diferencia existe entre una etiqueta HTML semántica y una no semántica?

• Margin: espacio que hay fuera de un elemento, separándolo de otros elementos. • Padding: espacio que hay dentro del elemento, entre el contenido y el borde del mismo.
