Pregunta 1

  1. ¿Qué es HTML y para qué se utiliza en el desarrollo web?

HTML es un lenguaje de marcado para crear páginas web. Se utiliza para crear y organizar el contenido de las páginas web, como textos, enlaces e imágenes, y sirve como base para aplicar estilos y funciones con CSS y JavaScript.

Pregunta 2

  1. ¿Qué es CSS y cómo se utiliza para dar estilo a una página web?

CSS es un lenguaje que se utiliza para dar estilo a las páginas web. Permite cambiar colores, tamaños de letra, márgenes, fondos y la posición de los elementos. Se puede usar directamente en el HTML con el atributo style, dentro de una etiqueta style en el head, o en un archivo externo .css vinculado al HTML.
